# CTT - a minimalistic text editor inside the terminal
## About
CTT is a Vim inspired text editor providing easier, more intuitive but less commands for enhancing your experience.
It is relatively fast since it is written in pure C and supports syntax highlighting (for now only for C code) by a .json configuration file.

# Controls
CTT only has a normal and insert mode. Normal is for navigating through the file and executing commands whereas the insert mode is used to type text.
There are also shortcuts but nothing fancy since CTT should stay minimal like that (similar to nano)
